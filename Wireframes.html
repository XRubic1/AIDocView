Wireframe Notes

  • Dashboard: Shows client summary, A/R balance, aging breakdown, warnings, and overdue invoices. Interactive pie chart for A/R breakdown.
  • Create Batch: Form to add invoices with validation. Shows batch summary table. Process Batch button submits for review.
  • Batch Review: Admin view showing all invoices in batch with status indicators. Shows held invoices with issues. Unattached documents section. Batch action buttons.
  • Status Colors: PND (gray), SUBMITTED (blue), HLD (red), OK (green), BILLED (orange), OPEN (yellow), PAID (green), FORCE_CLOSE (dark red)
  • Warning Icons: Red (!) for critical, Yellow (!) for review needed
